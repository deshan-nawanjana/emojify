# Emoji Search & Text Enhancement Tool

Emojify is a modern emoji search and text enhancement tool designed to make digital communication more expressive and engaging. It provides emoji discovery features and contextual text enhancement. The app allows users to search emojis by meaning, blend emojis naturally into sentences, and create more visually expressive messages.

Launch Now: [https://deshan.lk/apps/emojify](https://deshan.lk/apps/emojify)

## Key Features

- Search emojis instantly using keywords and meanings.
- Enhance sentences with context-aware emoji blending.
- Modern immersive interface with fast responsive interactions.

## Libraries and Frameworks Used

- [Vue.js](https://vuejs.org/) - Progressive framework for building user interfaces
- [JSZip](https://stuk.github.io/jszip/) - JavaScript library for creating, reading and editing .zip files
